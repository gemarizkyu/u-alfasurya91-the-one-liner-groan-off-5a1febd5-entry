## The joke

> I asked Dad why he brings a ladder to dinner — he said someone has to raise the steaks.

87 characters, 1 line, original. A classic dad-joke setup with a pun that lands (and then immediately makes you groan).

## How it works

`main.py` is a small deterministic Python program. Run it and it writes the joke above to `entry.txt` — the same line every time, no randomness, no dependencies.

```bash
python3 main.py
cat entry.txt
```
